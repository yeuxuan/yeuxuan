## 方法

**只做能交付的东西。** MCPane 已发布 8 个版本、累计 500+ 次下载，不停留在 demo。

**把复杂讲成简单。** 767 篇中文文档和一门 FDE 课程，把英文生态里的框架与源码拆开讲给中文开发者。

**按问题选技术。** TypeScript、Vue、Node.js、Go、Python、C#、Rust，哪个最合适就用哪个。
